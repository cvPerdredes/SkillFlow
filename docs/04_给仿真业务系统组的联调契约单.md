# 给仿真业务系统开发组的最小联调契约单（5 项对齐要求）

> **发送时间**：2026-11-25 上午（窗口 1 开工前对齐，避免两边各做各的导致 11/28 互评翻车）  
> **联调目的**：确保你们开发的电网仿真业务系统能够与 **SkillFlow v0.3 浏览器插件**无缝联动，一次性打通课题 #60 的“跨系统查询 + 批量填报 + 定位准确率评测 + 结果分布追问”。

## 请协助在仿真业务系统中落地的 5 项最小设计

### 1. 双固定端口 / 双独立子系统结构（打通课题必考“跨系统”）
- 请将仿真系统拆成 **2 个独立 Web 入口（固定端口或固定本地域名，不要每次重启随机换端口）**，例如：
  - **系统 A（如 `http://127.0.0.1:18761` 或独立域名）**：模拟**营销 2.0 / 客户与电量台账查询系统**（按单位/月份/户号查询客户与台账信息，带关联批号/户号字段）。
  - **系统 B（如 `http://127.0.0.1:18762` 或独立域名）**：模拟**工单 / 业务台账录入与审批系统**（填写供电单位、客户批号、表计号、申报电量等，提交后生成回执与台账列表）。
- **URL 约定**：如使用 SPA 路由（`#/page`）或页面参数（`?menuId=...`）请保持路径规则稳定，不要把无意义随机时间戳拼进静态菜单 URL。

### 2. 标准结果表格 & 含“明确成功/失败原因”的回执设计（支撑数据分布追问）
- **查询结果页（系统 A）**：请使用标准语义化 `<table>`（含 `<thead>`/`<tbody>`）展示结果明细行（至少包含供电单位、户号/批号、业务状态、数值列），避免用纯 `<div>` + 绝对定位伪装表格。
- **表单提交回执（系统 B）**：提交后页面应有清晰、可被 DOM 读取的状态容器，明确区分两类反馈：
  - **成功回执**：如 `status="ok"` + 明确提示文案与生成单号（如 `提交成功：单号 GD-202611-003，单位：杭州供电所`）；
  - **业务校验失败回执**：请**刻意内置 1–2 条确定性业务校验规则**（例如：`申报电量 <= 0` 或 `申报电量 > 50000` 报错“电量超限需核查”；`供电单位 === "未备案所"` 报错“单位代码不存在”），并在页面返回明确失败提示文案（**不要只弹浏览器原生 `window.alert` 阻塞页面**）。

### 3. 配套 10–20 条脱敏 CSV 样本数据（支撑 1→N 批量演示）
- 请随系统提供 1 份配套的 **10–20 行 UTF-8 CSV 样本文件**（字段与系统 B 表单一一对应），其中：
  - 80%–85% 为正常合法记录（覆盖 3–4 个不同供电单位、不同电量区间）；
  - **刻意混入 2–3 条会触发上述校验失败规则的异常记录**。
- 这样我们在现场演示“录制 1 条 → 导入 CSV 试跑 2 条再批量放行 → 追问按供电单位成功分布及失败原因占比”时，能立刻跑出真实有区分度的统计结果。

### 4. “页面轻改版开关”与“模拟登录态开关”（支撑硬指标评测与合规演示）
- **轻改版测试开关（非常加分！）**：建议在系统 A/B 角落或 URL 参数（如 `?layout=v2`）提供一个轻量改版切换开关：打开后仅改变部分输入框/按钮的 `id`（例如改成动态前缀 `ext-gen-9921`）和微调按钮所在 DOM 层级，**保留其 `<label>` / 文本含义不变**。这能让我们直接测出课题 #60 硬指标 **“元素定位准确率”**（证明传统 XPath 挂掉而本工具仍能准确命中）。
- **模拟登录与会话超时（可选但强烈建议）**：提供一个简易模拟登录页（含账号/密码框及可选“模拟验证码”开关）与“清空登录态”按钮，用于演示插件“不录存密码 + 登录失效时暂停交由人工接管登录后继续执行”的安全合规闭环。

### 5. 一期纯 MV3 插件需暂避的 4 类页面写法 + 离线启动
因为课题一期坚持**零安装成本的纯 MV3 浏览器扩展**路线，请仿真系统组在一期演示主路径中暂避以下写法：
1. ❌ **多层跨域 `iframe` 嵌套业务表单**（主菜单壳套跨域子系统时请使用新页面跳转或同源路由，勿把主表单嵌在跨域 `iframe` 中）；
2. ❌ **Canvas 绘制的表单控件 / 表格**；
3. ❌ **将 `<input type="file">` 本地附件上传设为提交必填卡点**（浏览器安全沙箱禁止扩展 JS 静默给 file input 赋值）；
4. ❌ **使用 `window.alert()` / `window.confirm()` 阻塞页面返回成功/失败提示**（请改用页面内联 Toast 或回执区域 DOM 元素）。
- **离线运行要求**：整套仿真系统须支持在单机 Windows 笔记本**完全断网离线一键启动**（11/30 演示与 12/20 路演现场均需零外部网络依赖）。
